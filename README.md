This Python Card Game is a playable command-line card game for 2-5 human players.
It's written in Python as a personal programming project. The code uses classes for the deck, players, rounds and tricks, with console interaction in a separate module.

## Run the game

Requires Python 3. Tested with Python 3.12. No third-party packages are needed.

Download or clone the repository, open a terminal in its folder, and run:

```bash
python card_game.py
```

On systems where Python 3 uses the `python3` command, run `python3 card_game.py` instead.

Enter 2-5 player names. Enter `0` when all players have been added; registration ends automatically after the fifth player.

During each turn:

- Enter `s` to view your current round score, or `p` to play a card.
- Select a card by its position in the displayed hand, starting from `1`.
- At the end of the game, enter `r` to restart or `q` to quit.

## Rules

- The deck contains 60 cards: four suits, each numbered 1-15.
- In round `n`, each player receives `n` cards from a newly shuffled deck. The suit of the next card becomes the round's bonus suit.
- Each trick consists of one card played by each player. The highest number wins. For equal numbers, the bonus suit takes priority; any remaining tie is won by the first matching card played.
- Winning a trick earns **2 points**. Playing a card of the bonus suit earns **1 additional point**, whether or not that card wins the trick.
- The starting player rotates after each trick. A new playing order is chosen at the start of each round.
- The game lasts `(60 - 1) // number_of_players` rounds, leaving at least one card to determine the bonus suit. Scores accumulate across rounds.
- The player with the highest total score wins. If final totals are tied, the current implementation reports the first tied player in registration order.

## Code structure

| File | Responsibility |
| --- | --- |
| `card_game.py` | Game setup, full game loop, final results and restart |
| `deck.py` | Deck creation, shuffling, dealing and bonus suit selection |
| `player.py` | Player names, hands and scores |
| `round.py` | Round setup, trick execution and total score updates |
| `trick.py` | Card play, winner determination, scoring and turn rotation |
| `ui.py` | Console input, input validation and result displays |

## Current scope

This version supports local human players sharing one terminal. Hands are displayed openly. Computer-controlled players are planned for a later version; they are not implemented in this release.
